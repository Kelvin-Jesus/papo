# Dependencies

* [iroh](/dependencies/iroh.md) - QUIC endpoints dialed by public key, with n0 address lookup and relay fallback.
* [iroh-gossip](/dependencies/iroh-gossip.md) - Topic broadcast layer every room runs on; has a dial quirk papo works around.
* [Claude Code channels](/dependencies/claude-code-channels.md) - Research-preview feature that lets the MCP server push messages into a session.
