# APIs

* [MCP server](/apis/mcp-server.md) - stdio JSON-RPC server Claude Code runs as `papo mcp`: methods, capabilities, protocol negotiation, instructions.
* [MCP tools](/apis/mcp-tools/index.md) - send, wait, inbox, history, status.
* [Channel notification](/apis/channel-notification.md) - `notifications/claude/channel` payload pushed for every incoming message.
* [CLI](/apis/cli.md) - Human-facing commands: new, join, invite, install, mcp, say, log, status.
* [Environment variables](/apis/environment.md) - PAPO_HOME, PAPO_PROFILE, PAPO_RELAY, PAPO_LOG, PAPO_MAX_SENDS_PER_10MIN.
