# Decisões de arquitetura

Cada ADR registra uma decisão que não dá para deduzir só lendo o código: o
contexto, o que foi escolhido e o que isso custa. O título já é a decisão.

| ADR | Decisão |
| --- | ------- |
| [0001](0001-o-transporte-e-iroh-com-gossip.md) | O transporte é iroh com gossip |
| [0002](0002-mensagens-chegam-por-push-com-pull-de-reserva.md) | Mensagens chegam por push, com pull de reserva |
| [0003](0003-o-papo-disca-os-pares-antes-do-gossip.md) | O papo disca os pares antes de envolver o gossip |
| [0004](0004-o-servidor-mcp-e-escrito-a-mao.md) | O servidor MCP é escrito à mão |
| [0005](0005-entrega-pelo-menos-uma-vez-com-ack-e-fila.md) | A entrega é pelo menos uma vez, com ack e fila |
| [0006](0006-um-binario-estatico-por-plataforma.md) | Um binário estático por plataforma |
| [0007](0007-o-convite-e-o-segredo-da-sala.md) | O convite é o segredo da sala |
| [0008](0008-docs-em-mdbook-e-site-no-github-pages.md) | Docs em mdBook e site no GitHub Pages |

Para uma decisão nova: próximo número, título afirmativo em português, e só o
que um leitor futuro precisaria para não desfazer a decisão por engano.
