# papo v0.4.0

Atualizar o papo virou um comando só: `papo update`.

### O que tem de novo

- **`papo update`.** Procura a última release e atualiza pelo mesmo caminho em que o papo foi
  instalado: `brew upgrade` no Homebrew, `scoop update` no Scoop, `cargo install` em `~/.cargo/bin`
  e, nas outras pastas, o `install.sh` da versão nova rodado no mesmo lugar. `papo update --check`
  só avisa se há versão nova, sem instalar. Nunca volta para uma versão mais antiga.
- **Pacotes do sistema e Windows.** Num papo instalado por `.deb`, `.rpm` ou AUR, ou pelo `.zip` no
  Windows, o comando mostra o que fazer em vez de agir sozinho: o primeiro caso pede `sudo`, e no
  Windows não dá para trocar um executável em uso.
- **Erro de perfil mais útil.** Rodar um comando sem `--profile` num computador onde o perfil tem
  outro nome agora lista os perfis que existem e mostra o comando certo, por exemplo
  `papo --profile nova leave`. Antes a mensagem mandava criar uma sala nova.

### Bom saber

- O `papo update` usa o `curl` para descobrir a versão nova. Linux, macOS e Windows 10 ou mais novo
  já trazem.
- Depois de atualizar, reconecte o servidor no Claude Code (`/mcp`). Os robôs acima do prompt são um
  plugin à parte e atualizam com `claude plugin update papo-robos@papo`.
- Quem está na v0.3.1 ou anterior atualiza desta vez pelo caminho de sempre. Daqui para frente,
  basta rodar `papo update`.

<summary>English</summary>

Updating papo is now one command: `papo update`.

- **`papo update`** finds the latest release and upgrades the way papo was installed (Homebrew,
  Scoop, `cargo install`, or the new release's `install.sh` into the same directory).
  `papo update --check` only reports. It never downgrades.
- `.deb`, `.rpm`, AUR and the Windows `.zip` get instructions instead of an automatic upgrade.
- An unknown profile now lists the existing ones and shows `papo --profile <name> <command>`.
- After updating, reconnect the server with `/mcp`; update the robots mod with
  `claude plugin update papo-robos@papo`.
