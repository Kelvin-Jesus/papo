# papo v0.3.0

Agora dá para ver, acima do prompt do Claude Code, quem da sala está trabalhando. Cada agente vira
um robozinho em pixel que digita num laptop durante o turno e para quando termina.

### O que tem de novo

- **Robôs da sala (mod `papo-robos`).** Um robô por agente da sala, desenhado acima do campo de texto.
  Enquanto o agente trabalha, o robô digita e o código rola na tela. Quando o turno acaba, ele solta
  os braços e a tela mostra um visto verde. Membro fora do ar aparece cinza. Você vê o seu robô e os
  dos colegas, e eles veem o seu.
- **Instalação pelo marketplace do repositório.** No Claude Code:
  `/plugin install papo-robos --marketplace Kelvin-Jesus/papo`. O mod é opcional: quem não instala
  não vê diferença.
- **Presença com estado de trabalho.** O `hello` ganhou o campo opcional `working`, e o `papo mcp`
  grava `activity.json` no perfil com quem da sala está trabalhando. Os detalhes estão no guia
  [Robôs](../guias/robos.md).

### Bom saber

- **Os dois lados precisam da v0.3.0 e do mod** para verem um ao outro trabalhando. Um colega com
  `papo` antigo continua na sala normalmente, mas o robô dele aparece sempre como "terminou".
- O campo novo é compatível nos dois sentidos: a v0.2.0 ignora o `working`, e um `hello` sem ele é
  lido como parado.
- Se a sessão de um colega cair no meio de um turno, o robô dele para de digitar em até 30 segundos.
- No app de desktop não há pixels: aparecem só os nomes e o estado de cada um.
- O `rustls` foi para a 0.23.46, que corrige os avisos RUSTSEC-2026-0346 a 0349.

<summary>English</summary>

You can now see who in the room is working, right above the Claude Code prompt.

- **Room robots (`papo-robos` mod).** One pixel robot per agent in the room: it types on a laptop
  while that agent is working, stops with a green check when the turn ends, and turns grey when the
  member is offline. Install it with `/plugin install papo-robos --marketplace Kelvin-Jesus/papo`;
  it is optional.
- **Presence carries a working state.** `hello` has a new optional `working` field, compatible both
  ways with older peers (an older peer simply shows as idle).
- `rustls` 0.23.46 fixes RUSTSEC-2026-0346 to 0349.

</details>
