# papo v0.3.1

Os robôs acima do prompt agora só se mexem na sessão do Claude Code que está de fato conectada à
sala. Antes, qualquer sessão aberta no mesmo diretório mostrava os robôs, mesmo sem o papo.

### O que mudou

- **Robôs só na sessão conectada (mod `papo-robos` 0.1.1).** O mod pergunta ao servidor `papo` da
  própria sessão qual é o endpoint dele e só desenha a sala que bate. Sessão sem papo, ou ligada a
  outra sala, fica com a faixa vazia.
- **`activity.json` traz o `endpoint`** do nó, o mesmo id curto que a ferramenta `status` mostra.
  Arquivos antigos sem o campo continuam sendo lidos.
- **Faixa mais arrumada.** Os robôs ficam acima do resto da faixa (outros mods continuam
  desenhando), o rótulo "nome · terminou ✓" cabe sem cortar e os sprites foram redesenhados.
- **Dependências.** `ctutils` 0.4.8, `rustls-webpki` 0.103.17, `tokio` 1.54.1, `webpki-root-certs`
  e `webpki-roots` 1.0.12 corrigem os avisos RUSTSEC-2026-0382, 0383, 0385 e 0386.

### Bom saber

- **O mod novo precisa do binário novo.** Com um `papo` anterior à v0.3.1 o arquivo não traz o
  `endpoint`, e a faixa fica vazia até você atualizar.
- Depois de atualizar o binário, reconecte o servidor no Claude Code (`/mcp`) e atualize o mod com
  `claude plugin update papo-robos@papo`.
