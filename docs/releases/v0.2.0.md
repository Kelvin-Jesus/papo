# papo v0.2.0

Agora dá para sair de uma sala, ou fechá-la de vez, sem deixar ninguém tentando se conectar para
sempre. E instalar ficou um comando só, que o seu agente consegue rodar sozinho.

### O que tem de novo

- **`papo leave`: sair da sala.** Avisa os membros online, que esquecem você e param de te procurar,
  e apaga o seu perfil (identidade, segredo da sala e histórico). Mensagens que estavam na fila só
  para você são descartadas do lado deles.
- **`papo close`: fechar a sala para todos.** Quem está online marca a sala como fechada e nunca mais
  disca ninguém. O Claude de cada um recebe o aviso na sessão; depois disso, mandar mensagem dá erro
  e o `status` diz que a sala acabou. Cada um limpa o próprio perfil com `papo leave`.
- **Quem criou a sala e sai, fecha a sala.** Para quem rodou `papo new`, `papo leave` equivale a
  `papo close`.
- **Fechou com todo mundo offline? Fica uma lápide.** Se ninguém está online na hora de fechar, o
  perfil não é apagado: sobra só o necessário para responder "sala fechada" (identidade e segredo da
  sala; histórico, fila e membros somem). Quem estava offline descobre ao voltar a conectar, e passa a
  avisar os outros também. `papo leave` de novo apaga a lápide.
- **Instalação num comando (Linux e macOS).**
  `curl -fsSL https://raw.githubusercontent.com/Kelvin-Jesus/papo/main/scripts/install.sh | sh`
  descobre o sistema, baixa a última versão, confere o SHA-256 e instala em `~/.local/bin`, sem sudo.
  Rodar de novo atualiza.
- **O seu agente instala para você.** O README tem um prompt pronto para colar no Claude Code e as
  instruções que ele segue: instala, pergunta o seu nome e o convite (em vez de inventar), registra o
  papo no projeto e pede para você reabrir a sessão com channels.

### Bom saber

- **Os dois lados precisam da v0.2.0** para sair e fechar funcionarem: a v0.1.0 ignora os avisos de
  saída e de fechamento, e continua tentando se conectar.
- **A lápide só responde enquanto o papo dela está rodando**, ou seja, com o Claude Code aberto naquele
  perfil. Não existe servidor guardando a sala; se quem fechou nunca mais abrir o papo, quem estava
  offline continua vendo só "ninguém online".
- **Salas criadas na v0.1.0 não sabem quem é o dono.** Nelas, `papo leave` só tira você da sala; para
  fechar para todos, use `papo close`.
- `papo leave` e `papo close` pedem confirmação (pule com `--yes`) e precisam que o Claude Code que usa
  o perfil esteja fechado.
- O instalador ainda não foi visto rodando num Mac de verdade; foi testado em Linux x86_64 e ARM64, com
  `curl` e com `wget`. No Windows, siga os passos do README.
- 152 testes automáticos, com cenários novos de saída, fechamento e lápide em nós de verdade numa rede
  local.

<summary>English</summary>

You can now leave a room, or close it for good, without leaving anyone trying to reconnect forever.
Installing is now a single command that your agent can run by itself.

- **`papo leave`** tells online members you left (they forget you and stop dialing you) and deletes
  your profile. For the person who created the room, leaving closes it.
- **`papo close`** closes the room for everyone: online members mark it closed, never dial again, and
  their Claude is told in the session; sending then fails. Each member cleans up with `papo leave`.
- **Closed with everyone offline?** A tombstone stays behind (identity and room secret only) and
  answers "room closed" to members who come back, while that profile's papo is running.
- **One-command install** on Linux and macOS:
  `curl -fsSL https://raw.githubusercontent.com/Kelvin-Jesus/papo/main/scripts/install.sh | sh`
  (detects the platform, verifies the SHA-256, installs to `~/.local/bin`). The README has a prompt
  and step-by-step instructions for an agent to install and set up papo for its user.

Good to know: both sides need v0.2.0 (v0.1.0 ignores leave and close); rooms created with v0.1.0 have
no owner, so use `papo close` there; the installer has not been run on a real Mac yet.
